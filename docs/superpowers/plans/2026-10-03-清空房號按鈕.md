# 設定欄「清空房號」按鈕 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在功能選單（設定欄）加入「🗑️ 清空房號」按鈕，二次確認後清空房號清單，但完整保留備料設定與所有用餐紀錄。

**Architecture:** 純函式 `clearRooms(state)` 放進既有的 `core.js` 純函式層（瀏覽器與 Node 共用），讓「設定與紀錄必須保留」這個關鍵行為由 `node:test` 自動化測試把關。`app.js` 只負責 DOM 事件綁定與呼叫。UI 為既有樣式系統（`.btn` / `.list-btn` / `.row-actions` / `--danger` 變數）加上新的確認 modal，不引入任何新相依。

**Tech Stack:** 原生 HTML / CSS / JavaScript（無框架）、`core.js` UMD 風格純函式層、`node:test` + `node:assert`（既有測試方案）、Service Worker 離線快取。

## Global Constraints

- 一律使用繁體中文撰寫 UI 文案、toast 訊息、程式碼註解與 commit 訊息（與既有程式碼一致）
- 不得引入任何新的 npm 相依套件；`core.js` 不得使用 `document`／`window` 等 DOM API
- `state` 的形狀固定為 `{ version, settings: { types, prep, mealSlots, sortMode }, rooms, daily }`（`app.js:47-59`）
- 清空**只**作用於 `state.rooms`；`state.settings`（含 `prep` 內所有係數）與 `state.daily` 必須原封不動保留
- `localStorage` key 維持 `rnb_data_v1`（`app.js:10`），不得變更
- 不得修改 `#importModal` 的既有匯入取代行為（`index.html:129`、`app.js:1162-1186`）
- 所有 DOM 元素 id 必須與本計畫所寫完全一致（大小寫敏感）
- 每一個 Task 結束前必須跑過 `node --check app.js core.js` 與 `node --test tests\core.test.js` 且全數通過
- 不做 undo／復原、不做清空前自動備份、不加全選反選（spec 已明列為範圍外）

```js
test('clearRooms: 清空房號，但 settings 與 daily 完整保留', () => {
  const state = {
    version: 1,
    settings: {
      types: [{ id: 'hot', label: '熱食', emoji: '🔥' }],
      prep: { jellyRatio: 1.1, eggRatio: 1.5, riceAdult: 0.2, riceChild: 0.1, specialDiv: 12 },
      mealSlots: [{ label: '07:30', enabled: true }],
      sortMode: 'name'

    rooms: [{ roomNumber: '101', breakfastType: 'hot' }, { roomNumber: '205', breakfastType: 'hot' }],
    daily: { '2026-10-03': { '101': 'completed' } }
  };
  const before = JSON.parse(JSON.stringify(state));
  const next = C.clearRooms(state);

  assert.deepStrictEqual(next.rooms, []);
  assert.deepStrictEqual(next.settings, before.settings);
  assert.deepStrictEqual(next.daily, before.daily);
  assert.strictEqual(next.version, 1);
});

test('clearRooms: 不 mutate 傳入的 state', () => {
  const state = {
    settings: { prep: { jellyRatio: 1.1 }, types: [], mealSlots: [], sortMode: 'room' },
    rooms: [{ roomNumber: '101' }],
    daily: {}
  };
  C.clearRooms(state);
  assert.strictEqual(state.rooms.length, 1);
});

test('clearRooms: rooms 本來就是空陣列時仍回傳空陣列', () => {
  const next = C.clearRooms({ version: 1, settings: {}, rooms: [], daily: {} });
  assert.deepStrictEqual(next.rooms, []);
});
```
