# 用餐時間排序 實作計畫

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 訂單模式的排序開關新增第三顆「用餐時間」鈕，有用餐時間的房依早→晚排前面，無時間／不用餐殿後，其餘行為不變。

**Architecture:** 在 `core.js` 新增純函式 `sortRoomsByMealTime(list)`（依既有 `timeOf` 解析 `mealTime`，早→晚；無有效時間者殿後且該組內依房號；同時間依房號）。`app.js` 的 `loadState` 接受 `sortMode: 'time'`，`renderOrderGrid` 依 `sortMode` 選用新函式，`render` 的開關 active 同步改為直接比對；`index.html` 的 `#sortToggle` 加第三顆鈕。

**Tech Stack:** 原生 JS（無框架、無建置步驟）。測試框架為 Node 內建 `node:test`。

**Spec:** `docs/superpowers/specs/2026-10-18-用餐時間排序-design.md`（commit `0ca4216`）

### Task 1: core.js 新增 sortRoomsByMealTime（純函式）＋測試

**Files:**
- Modify: `core.js:164`（於 `sortRoomsGrouped` 函式結束後、`clearRooms` 註解前插入）
- Modify: `core.js:171-175`（return 物件加入 `sortRoomsByMealTime`）
- Test: `tests/core.test.js`（尾端追加 6 個 test）

**Interfaces:**
- Consumes: `timeOf(label)`（core.js:103，回傳 `{h,m}` 或 `null`）、`roomKeyOf(r)`（core.js:139）、`roomNumberCmp(a,b)`（core.js:143）——皆為 core.js 內既有函式，無需新增。
- Produces: `sortRoomsByMealTime(list) → array`
  - `list`: room 陣列（可為 `undefined`）
  - 回傳**新陣列**（`list.slice()` 後排序），不修改輸入
  - 排序規則：
    1. `timeOf(r.mealTime)` 有值者依 `h` 升冪、再 `m` 升冪（早→晚），排前面
    2. 同時間或皆無有效時間 → 依 `roomNumberCmp(roomKeyOf(r))`（房號小→大）
    3. `timeOf` 回傳 `null`（空白、`不用餐`、格式無效如 `'9:7'`/`'13:00'`/`'08:3'`）者歸入「無時間」組，排最後
  - Task 2 會以 `C.sortRoomsByMealTime(byRoom)` 呼叫

- [ ] **Step 3: 實作 sortRoomsByMealTime**

```js

  function sortRoomsByMealTime(list) {
    const rooms = (list || []).slice();
    rooms.sort((x, y) => {
      const tx = timeOf(x && x.mealTime);
      const ty = timeOf(y && y.mealTime);
      if (tx && ty) {
        const d = tx.h - ty.h || tx.m - ty.m;
        if (d !== 0) return d;
      } else if (tx) return -1;
      else if (ty) return 1;
      return roomNumberCmp(roomKeyOf(x), roomKeyOf(y));
    });
    return rooms;
  }
```
