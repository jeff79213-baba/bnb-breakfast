# 房號與早餐 — 用餐時段依時間排序
**日期：** 2026-09-19
**範圍：** core.js + app.js（小型改動）

## 需求
時段新增後排序由小到大，不要用建立時間順序。

## 現況
`state.settings.mealSlots` 依新增順序；`renderSlotsList`、`enabledSlots` 皆照陣列順序顯示，因此時間欄選單也是新增順序。

## 設計
1. core.js 新增純函式 `sortSlots(slots)`：解析 `H:M`（1-12 時、分 0-59）按時→分升冪排序；無法解析的放最後、維持原相對順序。
2. app.js：
   - `saveMealSlots()` 儲存前先 `C.sortSlots` 排序（新增/勾選/刪除後都走這函式）。
   - `loadState()` 載入既有資料時排序一次，讓舊資料也一併排好。
3. 效果：設定清單、主頁面時間欄選單、修改房號選單全部由小到大；`enabledSlots` 無需改。
4. 補 1 個單元測試。

## 驗收
- 新增 9:30、8:15 → 清單顯示 8:15、9:30。
- 舊資料載入後也依時間排序。
