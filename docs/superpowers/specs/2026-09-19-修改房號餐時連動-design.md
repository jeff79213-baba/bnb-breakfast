# 房號與早餐 — 「修改房號」用餐時間欄與設定連動

**日期：** 2026-09-19
**範圍：** `index.html` + `app.js` 小型改動

## 需求

「修改房號」視窗（按表格「改」按鈕開啟）內原本的用餐時間是手打文字欄。使用者要求：
- 欄位**不可手打**，只能點下去選擇
- 跳出選單內容＝目前「早餐用餐時間」設定中**已勾選的時段**＋「🚫 不用餐」（＋清除空白）
- 與設定頁連動：設定頁改勾選狀態，此處選單即時同步

## 現況

- 表格時間欄已有 `openTimePicker`：跳出 `timePickerModal`，選完直接寫入 `room.mealTime` + `saveState()` + `render()`（app.js:1413）
- `修改房號` 視窗的 `orderTimeInput` 是 `type=text`，存檔時讀取 `.value`（app.js:1271）

## 設計

1. **index.html**：`orderTimeInput` 改為 `readonly`，placeholder 改「點擊選擇時段」。
2. **app.js**：
   - 抽出共用 helper `renderTimePickerOptions(onPick)`：負責渲染「勾選時段＋不用餐＋清除」，並把每個按鈕的點擊交給 `onPick(value)` 回呼。`openTimePicker` 改用它（onPick＝寫入 room + saveState + render）。
   - 新增 `openOrderTimePicker()`：開啟同一 `timePickerModal`，onPick＝把值填入 `orderTimeInput`（**不直接存**），由「確認修改」流程才寫入 room。
   - 綁定：`openOrderEdit` 內綁 `orderTimeInput` 的 `click` → `openOrderTimePicker()`。
3. **連動**：兩份選單都讀 `C.enabledSlots(state.settings.mealSlots)`，共用來源，設定頁與此處天然同步。

## 測試

- 既有單元測試維持 9/9 通過。
- 此功能為純跨欄位選單流程，無新增純函式，不強制新增單元測試。

## 驗收

- 「修改房號」視窗用餐時間欄無法手打。
- 點欄位跳出選單：顯示勾選時段＋不用餐＋清除。
- 選擇後值填回欄位；按確認修改才生效；設定頁勾選增減後此選單同步。
