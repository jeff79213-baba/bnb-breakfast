# 房號與早餐 — 早餐用餐時間：滾輪式時段選擇器

**日期：** 2026-09-19
**範圍：** `index.html` + `style.css` + `app.js`（小型改動）

## 需求

「早餐用餐時間」設定視窗的時段輸入目前是手打文字（`例如 8:15`）。使用者要求改為**滾輪式選擇**：
- 小時 1～12（不標上午/下午）
- 分鐘 00/05/10…55（每 5 分一格）
- 選完後值出現在新增欄位，按下「新增」後加入清單並可勾選啟用（既有流程不變）

## 現況

- `index.html`：`#slotsInput`（手打 input）＋ `#slotsAddBtn`（新增）在 `#mealSlotsModal` 內
- `app.js`：`$('slotsAddBtn').click` 讀 `$('slotsInput').value` → `C.addSlot(...)` → `saveMealSlots()` → `renderSlotsList()`；`slotsInput` Enter 觸發新增
- `renderSlotsList()` 已渲染 checkbox（`data-slot-check`）＋ 刪除鈕，沿用不變

## 設計

**A. 自訂 CSS 滾輪（採用）**

1. `index.html`：在 `#slotsInput` 上方插入滾輪選擇區：
   - 兩欄 `<div class="wheel-col" data-wheel="hour">`（1–12）與 `data-wheel="min"`（05/10/…/55＋00）
   - 每欄內放數個選項 div（`data-val`），外層「目前選中」指示線置中
   - 下方保留 `#slotsInput` 作為回填顯示欄位＋`#slotsAddBtn`
2. `style.css` 新增：
   - `.wheel-col`：固定高度（約 3 個選項高），`overflow-y:auto`、`scroll-snap-type:y mandatory`，每項 `scroll-snap-align:center`
   - 中間高亮線（前置 `::before`／`::after` 或絕對定位線），隱藏捲軸
3. `app.js`：
   - 滾輪初始化 `initWheel()`：產生選項、預設 8:00、scroll 對齊、回填 `slotsInput`＝`H:M`（M 補零）
   - scroll 事件（含卷動停止判斷）→ 計算最接近的 snap 選項 → 更新高亮與回填
   - `openSlotsModal()` 時呼叫 init 並對齊目前值（讀第一個既有時段或預設 8:00）
   - 既有 `slotsAddBtn` 流程不變（讀 `slotsInput.value`）

**連動：** 選項值一律回填 `slotsInput`，新增後進 `state.settings.mealSlots`，主頁面時間欄與修改房號選單自動同步（共用資料）。

## 測試

- 既有單元測試維持 9/9 通過。
- 此為互動 UI，無新增純函式，不強制新增單元測試。

## 驗收

- 設定視窗出現兩欄滾輪（1–12、00/05/…/55），無需手打。
- 選中值即時顯示在「新增」欄位（如 `8:15`）。
- 新增後清單出現並可勾選啟用；主頁面時間欄選單出現該時段。
